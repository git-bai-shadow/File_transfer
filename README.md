# 🌟 现代化局域网文件共享系统

这是一个基于 Python 和 Flask 构建的、**界面现代化**的轻量级局域网文件共享系统。采用**毛玻璃效果**和**流畅动画**的现代UI设计，提供功能丰富的 Web 界面，允许用户在局域网内部方便、高效地管理和分享文件。

![001.png](001.png)

## ✨ 主要功能

### 🎨 现代化UI设计
-   **毛玻璃效果界面**: 采用backdrop-filter技术实现真实的毛玻璃质感
-   **动态背景**: 渐变背景配合粒子动画效果
-   **流畅动画**: 页面加载、交互反馈、状态切换的平滑过渡
-   **现代配色**: 苹果风格的蓝色渐变主题，支持深色模式
-   **响应式设计**: 完美适配桌面、平板、手机等各种设备

### 📁 文件管理功能
-   **三栏式专业布局**:
    -   **左侧文件树**: 可交互、可折叠的完整目录树，自动展开并高亮当前路径
    -   **中间文件列表**: 清晰的表格展示，包含文件名、修改时间和大小
    -   **右侧详情面板**: 单击文件或文件夹，即可显示详细信息、下载按钮和分享二维码
-   **智能文件上传**: 
    -   支持拖拽上传，直接将文件拖入上传区域
    -   多文件批量上传，实时预览文件列表
    -   优雅的模态框设计，不干扰当前浏览操作
-   **二维码分享**: 轻松扫描右侧面板的二维码，即可在移动设备上获取文件下载链接
-   **用户安全认证**: 通过登录页面保护共享内容，只有授权用户才能访问

### 🚀 用户体验增强
-   **微交互动画**: 按钮悬停、文件选择、加载状态的精致动效
-   **视觉反馈**: 选中状态高亮、加载骨架屏、成功操作提示
-   **无障碍支持**: 键盘导航、高对比度模式、屏幕阅读器友好
-   **性能优化**: GPU加速动画、智能预加载、流畅滚动体验

## 🛠️ 安装与启动

1.  **克隆或下载项目**
    将本项目所有文件放置在你的电脑上。

2.  **安装依赖**
    打开终端（或命令行），进入项目根目录，然后运行以下命令来安装所有必需的 Python 包：
    ```bash
    pip install -r requirements.txt
    ```
    *如果 `requirements.txt` 不存在，请手动安装:*
    ```bash
    pip install Flask "qrcode[pil]"
    ```

3.  **启动应用**
    在项目根目录下，运行以下命令来启动 Web 服务器：
    ```bash
    python app.py
    ```
    服务器默认会在 `0.0.0.0:5000` 上运行。

## 🚀 使用方法

1.  **访问系统**: 在同一局域网的设备上，打开浏览器并输入 `http://<服务器的IP地址>:5000`。
2.  **登录**: 使用默认凭据 `admin` / `password` 登录。
3.  **浏览文件**:
    -   在左侧文件树中点击文件夹名称进行跳转。
    -   点击文件夹前的箭头 `▶` 来展开或折叠子目录。
    -   中间区域会显示当前目录下的所有文件和文件夹。
4.  **查看详情与下载**:
    -   单击中间列表中的任意一项，右侧详情面板会显示其详细信息。
    -   如果选择的是文件，面板中会出现“下载文件”按钮。
    -   使用手机扫描二维码可快速分享。
5.  **上传文件**:
    -   点击页面右上角的“上传文件”按钮。
    -   在弹出的窗口中，点击“选择文件”并选取一个或多个文件。
    -   点击“确认上传”，文件将被上传到你当前所在的目录。 

## 💡 使用指南

### 基本操作
1. **文件浏览**: 左侧文件树点击文件夹导航，中间区域查看文件列表

- **批量操作**: 支持多文件同时上传
- **移动端适配**: 手机访问自动切换为移动端布局
- **键盘导航**: 支持Tab键和方向键操作

## 🔧 故障排除

**常见问题:**
- **上传失败**: 检查uploads目录权限
- **样式异常**: 确认浏览器支持backdrop-filter
- **无法访问**: 检查防火墙和网络设置
- **登录问题**: 确认用户名密码配置
